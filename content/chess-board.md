# Autonomous Chess Board
Dates: [dates]

Tools & Skills: Raspberry Pi, SolidWorks, Computer vision, 3D printing, Laser cutting, Laser engraving

## Summary
A chess board that plays back against you: computer vision reads the game and a magnet on an H-bot gantry beneath the board drags the pieces.

## Details
Runs on ChessOS. Vision can detect pieces and sort them by color, but not consistently yet. Next: track each piece as it moves through the game instead of recognizing piece types (knight vs. king).
